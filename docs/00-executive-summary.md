# ۰۰ — خلاصهٔ مدیریتی

**تاریخ:** ۲۰۲۶-۱۱-۱۱ · **فاز:** M0 (تحقیق و طراحی) · **وضعیت:** تکمیل‌شده

## ۱. مسئله

LetsEnhance یک سرویس ابری است: قوی، اما (الف) آفلاین نیست، (ب) اعتباری/اشتراکی است، (ج) تصویر کاربر از دستگاه خارج می‌شود، (د) در نسخهٔ وب به سقف مگاپیکسل و تعداد تصویر وابسته است، (ه) برای مصارف حرفه‌ای (۱۶ بیت، CMYK، TIFF چندصفحه، RAW) ابزار بومی ارائه نمی‌دهد.

هدف ما: **همان کیفیت یا بهتر، روی دستگاه خود کاربر، روی هر سخت‌افزاری، بدون اینترنت.**

## ۲. آن‌ها چه دارند (خیلی خلاصه)

۷ مدل بزرگ‌نمایی (`Prime`, `Balanced`, `Gentle`, `Strong`, `Ultra`, `Digital Art`, `Old Photo`)، اصلاح نور `Light AI`، حذف نویز/آرتیفکت JPEG، شارپن، حذف پس‌زمینه، بزرگ‌نمایی ۱x–۱۶x، تعیین DPI، دستهٔ ۲۰ فایلی، `Try all`، مولد تصویر، Chat Editor، Image-to-Video و API (`Claid.ai`). زیرساخت: A100 MIG روی GKE + Triton، اتوسکیل تا ۱۵۰+ تصویر/ثانیه.

## ۳. تصمیم‌های کلیدی معماری (و دلیلشان)

| تصمیم | انتخاب | دلیل | جایگزین رد‌شده |
|---|---|---|---|
| زبان هسته | **C++20** | دسترسی مستقیم به ncnn/ORT، کنترل حافظه و SIMD، قابل استفاده در JNI/Swift/C-ABI | Rust خالص (اکوسیستم استنتاج تصویر ضعیف‌تر)، Python (توزیع سخت) |
| استنتاج | **ncnn (Vulkan/CPU) + ONNX Runtime (EPهای سخت‌افزاری)** | ncnn روی هر GPU با Vulkan و حتی CPU عالی است؛ ORT برای NPU/DirectML/CoreML | فقط PyTorch (باینری چندصد مگابایتی، روی موبایل غیرعملی) |
| پوستهٔ دسکتاپ | **Tauri 2 + React/TS** | باینری کوچک (~۱۰ مگابایت)، وب‌ویو سیستم، UI سریع | Electron (۱۵۰MB+ و RAM بالا) |
| اندروید | **Kotlin + Compose + JNI به همان هسته** | حداکثر کارایی، دسترسی به Vulkan/NNAPI-less، Asset Delivery برای مدل‌ها | Tauri mobile (بلوغ پایین برای JNI سنگین) |
| iOS/مک | **SwiftUI + Metal/CoreML** | دسترسی به ANE/Metal و الزامات App Store | Flutter (افت کارایی و پیچیدگی FFI) |
| موتور کیفیت | **GAN/CNN به‌عنوان خط پایه + Diffusion به‌عنوان تیر اختیاری** | خط پایه روی هر دستگاهی اجرا می‌شود؛ Diffusion فقط ۸GB+ | Diffusion-only (روی اکثر دستگاه‌ها غیرقابل اجرا) |
| مسیر بدون GPU | **مدل‌های سبک INT8 + مسیر کلاسیک پیشرفته** | «همیشه جواب می‌دهد» یک الزام محصول است | «بدون GPU پشتیبانی نمی‌شود» |
| مدل‌های غیرتجاری | **پلاگین اختیاری با هشدار** | کیفیت بالاتر برای کاربر شخصی، ریسک حقوقی صفر برای هستهٔ تجاری | بسته‌بندی پیش‌فرض (ریسک حقوقی) |

## ۴. تفاوت‌های ما با آن‌ها («قوی‌تر» یعنی چه؟)

1. **آفلاین و خصوصی** — هیچ آپلودی وجود ندارد.
2. **بدون سقف مگاپیکسل** — تا حد حافظهٔ دستگاه (با پردازش نواری/کاشی و رمزنویسی تدریجی روی دیسک).
3. **کیفیت حرفه‌ای** — ۱۶ بیت، ICC، CMYK، TIFF/PDF، حفظ EXIF/DPI، خروجی AVIF/JXL.
4. **مدل‌های بیشتر + انتخاب خودکار** — روتر محتوا (عکس/انیمه/متن/عکس قدیمی) + `Try all` محلی.
5. **ترکیب مدل‌ها** — چیزی که سرویس ابری نمی‌کند: SR + بازسازی چهره + حذف آرتیفکت + اصلاح رنگ در یک گراف قابل‌ویرایش، با حفظ سبک.
6. **دستهٔ نامحدود + CLI + واچ‌فولدر** برای پایپ‌لاین‌های حرفه‌ای.
7. **شفافیت** — بنچمارک عمومی، بدون watermarks، بدون اعتبار.

## ۵. ریسک‌های اصلی (خلاصه)

| ریسک | اثر | کاهش |
|---|---|---|
| شکاف کیفیت با مدل‌های مولد ابری (Ultra/SUPIR-class) | بالا | تیر اختیاری Diffusion + دیستیل مدل + روتر هوشمند |
| تنوع سخت‌افزار اندروید و درایور Vulkan | بالا | تست روی ماتریس دستگاه، timeout + fallback به CPU، حالت «سازگار» |
| حجم مدل‌ها و قوانین استور | متوسط | Play Asset Delivery، دانلود در اولین اجرا، INT8 |
| لایسنس مدل‌ها | متوسط | کاتالوگ با فیلد `commercial_ok`، جداسازی پلاگین |
| انتظارات عملکرد روی CPU قدیمی | متوسط | نمایش شفاف ETA، پیش‌نمایش کاشی، حالت سریع |
