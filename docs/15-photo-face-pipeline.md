# ۱۵ — مشخصات پایپ‌لاین عکس واقعی و چهرهٔ واقعی

> قاعدهٔ طلایی: **هرگز اجازه ندهید مدل SR عمومی، چهره را بازسازی کند.** چهره جدا پردازش، جدا ارزیابی و سپس با ماسک ترکیب می‌شود.

---

## ۱. اصول طراحی

1. **چهره = مسیر مستقل.** پس‌زمینه/بدن با SR کاشی‌ای، چهره با پایپ‌لاین تخصصی.
2. **دروازهٔ هویت اجباری.** هیچ خروجی چهره‌ای بدون سنجش شباهت به منبع منتشر نمی‌شود.
3. **وفاداری قابل‌تنظیم.** کاربر بین «محافظه‌کار» و «جسور» انتخاب می‌کند؛ پیش‌فرض = محافظه‌کار.
4. **بدون زیباسازی.** هیچ smoothing سراسری، هیچ تغییر فرم، هیچ روشن‌سازی پوست.
5. **شفافیت.** اگر بازسازی حدسی است (چهرهٔ کوچک، نیم‌رخ، تاری شدید) به کاربر گفته می‌شود.
6. **تصمیم‌گیری مبتنی بر اندازه‌گیری.** هر آستانه در بخش ۷ عدد دارد و در `17-evaluation-protocol.md` کالیبره می‌شود.

## ۳. تحلیل و برنامه‌ریزی

### ۳.۱ متریک‌های تحلیل

| متریک | روش | استفاده |
|---|---|---|
| نویز | انحراف معیار Laplacian در نواحی تخت + تخمین نویز رنگی | شدت denoise |
| تاری | histogram گرادیان + تخمین کرنل (در صورت نیاز) | deblur / مدل Strong |
| فشردگی JPEG | انرژی در فرکانس ۸×۸ + جدول quantization اگر موجود | decompress |
| moiré | طیف فرکانسی الگوی تکراری | فیلتر moiré |
| محتوا | کلاسیفایر کوچک (photo/anime/text/old/screenshot) | انتخاب مدل |
| چهره | SCRFD | مسیر چهره |
| متن | DBNet-lite یا heuristic | مسیر Gentle |

### ۳.۲ کاشی‌بندی آگاه به چهره

```text
faces = detect(image)
protected = inflate(face_boxes, 0.6 * max(w,h))     # حاشیهٔ امن دور هر چهره
grid = plan_grid(W, H, tile, overlap)
grid = shift_boundaries_away_from(protected, grid)  # مرز کاشی از چهره عبور نکند
for face in faces where face.size >= MIN_FACE:
    mask_face_region_from(bg_sr)                    # چهره بعداً کامپوزیت می‌شود
```

قواعد:

- هیچ کاشی‌ای نباید از وسط چهره بگذرد (خطای رایج = چشم نصفه).
- اگر چهره از کاشی بزرگ‌تر است → کل چهره در یک پاس جدا (بدون تقسیم) یا با کاشی مخصوص چهره.
- ناحیهٔ چهره در لایهٔ پس‌زمینه با ماسک dilated خالی می‌شود تا دو بازسازی با هم تداخل نکنند.
- برای چهره‌های چسبیده (گروهی)، باندل هر چهره جدا ولی با ترتیب ثابت پردازش می‌شود.

### ۳.۳ انتخاب پاس‌ها (scale)

| مقیاس درخواستی | پاس‌ها | یادداشت |
|---|---|---|
| ۲x | یک پاس ۲x یا ۴x + downscale | دان‌اسکیل با Lanczos + دیتزر |
| ۴x | ۴x مستقیم | پیش‌فرض |
| ۸x | ۴x + ۴x (با بازنمونه‌برداری میانی ۲x) یا مدل ۸x | پرهیز از «سطح تخت» |
| ۱۶x | ۴x → ۴x → ۴x با کنترل بافت | فقط تیر A؛ هشدار کیفیت |

## ۴. برش و تراز چهره (Alignment)

```text
landmarks = detect_landmarks(face)
M = estimate_similarity_transform(landmarks, arcface_template_112)
aligned = warpAffine(image, M, size=512)        # 512 برای مدل چهره
inverse = invert(M)
```

- قالب ۱۱۲×۱۱۲ برای استخراج هویت (ArcFace) و ۵۱۲×۵۱۲ برای بازسازی.
- padding بازتابی برای چهره‌های نزدیک لبه.
- ذخیرهٔ `inverse` برای paste-back دقیق (بدون جابه‌جایی یک پیکسلی).

## ۵. بازسازی چهره

### ۵.۱ حالت Natural (پیش‌فرض)

| مرحله | مدل | پارامتر |
|---|---|---|
| ۱. بازسازی پایه | GFPGAN v1.4 (تجاری‌امن) **یا** CodeFormer (پلاگین) | شدت ۰٫۳–۰٫۵ |
| ۲. بازسازی بافت | Real-ESRGAN روی ناحیهٔ پوست/مو با وزن کم | ۰٫۲–۰٫۴ |
| ۳. ترکیب فرکانسی | low-freq از SR، high-freq محدود از مدل چهره | نسبت انرژی ۰٫۸–۱٫۲ |

> **چرا ترکیب فرکانسی؟** مدل چهره ساختار را درست می‌کند ولی بافت را صاف می‌کند؛ SR بافت را می‌آورد ولی ساختار را خراب می‌کند. تفکیک فرکانسی، بهترینِ هر دو را می‌دهد.

### ۵.۲ حالت Reference-locked

```text
refs = load_references(1..4)                  # همان شخص، تأییدشده
id_ref = mean(embed_arcface(ref))             # میانگین امبدینگ
restored = ref_face_model(aligned, refs)      # InstantRestore/FaceMe/RestorerID
id_out = embed_arcface(restored_aligned)
if cos(id_out, id_ref) < TAU_REF: reject_and_fallback()
```

قواعد:

- رفرنس باید از همان شخص باشد؛ اگر `cos(ref_i, ref_j) < 0.5` بین رفرنس‌ها ⇒ هشدار «رفرنس‌ها یک شخص نیستند».
- رفرنس‌های مختلف (نور/پوز) بهتر از ۴ عکس مشابه‌اند.
- در حالت batch: خوشه‌بندی چهره‌ها با ArcFace → یک رفرنس برای هر خوشه → سازگاری بین عکس‌های یک آلبوم.

### ۵.۳ فالبک‌ها (به ترتیب)

```
1. Reference-locked  → اگر رفرنس معتبر بود
2. Blind CodeFormer (پلاگین) با fidelity بالا
3. GFPGAN با شدت پایین
4. SR عمومی روی ناحیهٔ چهره (Real-ESRGAN x4plus)
5. بدون تغییر چهره (فقط بزرگ‌نمایی bicubic + شارپن ملایم) + هشدار
```

هیچ‌گاه مرحلهٔ ۵ به‌عنوان «بهبود» تبلیغ نمی‌شود؛ در گزارش QA «بازسازی نشد» ثبت می‌شود.

## ۶. دروازهٔ هویت (Identity Gate)

### ۶.۱ تعریف

```
id_src  = embed_arcface(aligned_source)
id_out  = embed_arcface(aligned_restored)
id_ref  = embed_arcface(reference)            # اگر موجود
score_src = cos(id_out, id_src)
score_ref = cos(id_out, id_ref)               # اگر موجود

accept  if (score_ref >= 0.80) or (no_ref and score_src >= T_src)
soft    if score in [T_low, T)  → کاهش شدت/ترکیب محافظه‌کار
reject  if score < T_low        → فالبک مرحلهٔ بعد
```

### ۶.۲ آستانه‌های پیشنهادی (کالیبره در P3)

| تیر | `T_src` قبول | `T_low` رد | `TAU_REF` |
|---|---|---|---|
| چهرهٔ بزرگ و شارپ (≥۱۹۲px) | ۰٫۷۰ | ۰٫۵۵ | ۰٫۸۰ |
| چهرهٔ متوسط (۹۶–۱۹۲px) | ۰٫۶۵ | ۰٫۵۰ | ۰٫۷۸ |
| چهرهٔ کوچک (۴۸–۹۶px) | ۰٫۶۰ | ۰٫۴۵ | ۰٫۷۵ |
| چهرهٔ خیلی کوچک (<۴۸px) | فقط محافظه‌کار | — | — |

> مبنا: در ادبیات، آستانهٔ «همان شخص» با ArcFace معمولاً فاصلهٔ کسینوسی ۰٫۴ (شباهت ۰٫۶) و در خطوط تولید مولد، آستانهٔ پذیرش ۰٫۵۵ گزارش شده است. آستانه‌های ما محافظه‌کارترند و در مجموعهٔ طلایی با داوری انسانی کالیبره می‌شوند.

### ۶.۳ سیاست «Soft»

- اگر امتیاز در بازهٔ خاکستری است: شدت بازسازی را ۵۰٪ کاهش بده، دوباره بسنج، بهترین را نگه دار.
- حداکثر ۲ تلاش؛ سپس فالبک.
- در UI: «بازسازی محافظه‌کار (اطمینان متوسط)».

## ۷. ترکیب (Compositing)

```text
mask = face_parsing(aligned_restored)          # پوست، مو، چشم، لب، عینک
mask = feather(mask, radius=7px)
mask = exclude(mask, eyes_and_teeth_if_low_conf)
color_match(restored, target=neighborhood)     # mean/std در LAB
composite = poisson_or_laplacian_blend(bg_sr, restored, mask)
```

قواعد:

- **چشم و دندان** حساس‌ترین نواحی‌اند؛ اگر مدل چهره آن‌ها را تغییر داده، از نسخهٔ SR عمومی استفاده کن (تشخیص با اختلاف لندمارک/هیستوگرام ناحیه).
- **خط فک و گوش** اغلب باعث «بریدگی» می‌شوند؛ ماسک باید ۲–۳px بیرون بزند و feather داشته باشد.
- **تطبیق رنگ** اجباری است؛ در غیر این صورت «صورت چسبانده‌شده» دیده می‌شود.
- **ماسک مو** باید از face parsing بیاید تا موهای کنار صورت صاف نشوند.

## ۸. بافت، جزئیات و واقع‌گرایی

| تکنیک | هدف | پارامتر اولیه |
|---|---|---|
| Frequency separation | حفظ ساختار + بافت | split در σ≈۲–۴px |
| Multi-band sharpening | تیزکردن بدون هاله | ۳ باند، حد ۰٫۲ |
| Grain synthesis | جلوگیری از «پلاستیک» | نویز فیلترشده هم‌رنگ بافت |
| Edge-aware detail injection | بافت پوست/پارچه | guided filter |
| Halo suppression | حذف هالهٔ شارپن آیفون | تشخیص + کاهش محلی |

**قانون:** Sharpen نهایی روی پوست ≤ ۵۰٪ مقدار روی لبه‌های سخت (پارچه/معماری) باشد.

## ۹. رنگ و نور (Light AI برای چهره)

1. وایت‌بالانس با مرجع خاکستری/پوست (نه فقط gray-world).
2. منحنی تن جداگانه برای **پوست** (حفظ رنگ، بدون روشن‌سازی ناخواسته).
3. سایه/هایلایت در فضای خطی.
4. محافظت از اشباع: `vibrance` به‌جای `saturation` سراسری.
5. **ΔE guard:** اگر تغییر رنگ پوست > ۳، شدت را کم کن.
6. تست لایه‌ای: Fitzpatrick I–VI؛ هیچ روشن‌سازی سیستماتیک.

## ۱۰. موارد خاص

| مورد | تشخیص | رفتار |
|---|---|---|
| چهرهٔ کوچک | اندازه bbox | بدون بازسازی هویت‌محور؛ فقط SR محافظه‌کار + هشدار |
| نیم‌رخ (|yaw|>۴۵°) | поза | شدت پایین، فالبک سریع |
| عینک | parsing/landmark | محافظت قاب و عدسی؛ عدم تولید انعکاس جعلی |
| ریش/سبیل | parsing | حفظ الگو؛ عدم صاف‌کردن |
| آرایش | رنگ/بافت | حفظ؛ عدم «پاک‌سازی» |
| دندان | ناحیهٔ دهان | عدم تولید دندان جدید |
| چشم بسته | landmark | عدم بازکردن چشم! |
| دوقلو/شخص مشابه | رفرنس | تأیید دستی رفرنس در batch |
| کودک | اندازه/تناسبات | مدل/شدت محافظه‌کار، تست جدا |
| سالمند | چین‌وچروک | حفظ چروک (نه حذف) |
| پوست تیره | تحلیل رنگ | منحنی جدا + تست انصاف |
| عکس گروهی | >۲ چهره | پردازش مستقل + سازگاری رنگ بین چهره‌ها |
| ماسک/کلاه | parsing | حفظ؛ عدم تولید موی جعلی |

## ۱۱. سازگاری در Batch (آلبوم)

```
1. استخراج امبدینگ همهٔ چهره‌ها
2. خوشه‌بندی (cosine ≥ 0.55) → identity clusters
3. برای هر خوشه: انتخاب ۱–۴ رفرنس با بهترین کیفیت (شارپ/روشن/روبه‌رو)
4. پردازش هر چهره با رفرنس خوشهٔ خودش
5. یکسان‌سازی رنگ/شدت بین عکس‌های یک خوشه
```

نتیجه: در یک آلبوم، یک شخص در همهٔ عکس‌ها «همان‌طور» بازسازی می‌شود — چیزی که سرویس‌های ابری معمولاً نمی‌کنند.

## ۱۲. گزارش QA (بدون تلمتری)

برای هر خروجی یک JSON کنار فایل:

```json
{
  "schema": 1,
  "input": "IMG_1234.HEIC",
  "output": "IMG_1234_natural_4x.png",
  "faces": [
    { "id": 0, "size_px": 210, "yaw": 8, "identity_src": 0.74,
      "identity_ref": 0.83, "gate": "accepted", "fallback": null,
      "hallucination_risk": "low" }
  ],
  "global": { "noise": 0.31, "jpeg_q": 42, "model": "atlas-photo-v1",
              "tile": 384, "backend": "vulkan", "time_s": 12.4 },
  "warnings": []
}
```

- `hallucination_risk` از اختلاف دو مدل/دو seed یا از انرژی فرکانس بالا در نواحی بی‌بافت محاسبه می‌شود.
- نقشهٔ حرارتی اختیاری در UI (نواحی مشکوک).

## ۱۳. شبه‌کد مرجع

```cpp
Result process(Image img, Options opt) {
  auto lin = to_linear(img);
  auto a = analyze(lin);
  auto faces = detect_faces(lin);
  auto plan = make_plan(lin.size(), a, faces, opt);

  auto clean = deblock_denoise(lin, a);            // نسخهٔ اصل حفظ می‌شود
  auto bg = sr_tiled(clean, plan, opt);
  auto out = bg;

  for (auto& f : plan.faces) {
    if (f.size_px < MIN_FACE_PX) { mark_skipped(f); continue; }
    auto aligned = align(clean, f);
    auto refs = opt.reference_mode ? refs_for(f) : {};
    auto restored = restore_face(aligned, refs, opt.fidelity);
    auto gate = identity_gate(aligned, restored, refs, f);
    if (gate.rejected) restored = fallback_face(aligned, f, opt);
    auto mask = parse_mask(restored);
    auto color = match_color(restored, out, f);
    out = composite(out, color, mask, f);
  }

  out = detail_and_grain(out, plan);
  out = color_light(out, opt.light, a);
  return encode(out, opt, qa_report(plan, faces));
}
```
