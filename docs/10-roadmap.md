## ۳. M1 — MVP ویندوز (۶–۸ هفته)

**هدف:** یک کاربر ویندوزی بتواند ۵۰ عکس را با کیفیت خوب و بدون دانش فنی بزرگ کند.

| هفته | کار |
|---|---|
| ۱ | اسکلت `atlas-core` (CMake، C ABI، بافر/تصویر، decode/encode)، CI اولیه |
| ۲ | بک‌اند ncnn + Vulkan + CPU؛ probe + بنچمارک؛ بارگذاری مدل |
| ۳ | Tiling + blending + گراف پایپ‌لاین JSON + مرحلهٔ `sr` |
| ۴ | صف کار، پیشرفت، لغو، ازسرگیری، لاگ/خطا |
| ۵ | Tauri UI: drag&drop، صف، پنل مدل/مقیاس، پیش‌نمایش قبل/بعد، ETA |
| ۶ | پریست‌ها، خروجی (JPEG/PNG/TIFF)، نام‌گذاری، پوشهٔ خروجی |
| ۷ | بهینه‌سازی، تست روی ۵ دستگاه، اصلاح باگ‌ها |
| ۸ | بسته‌بندی (NSIS + Portable)، امضا، مستند کاربر، انتشار 0.1 |

**DoD**

- ۴ مدل: `x4plus`, `x4v3`, `anime6B`, `SPAN`.
- اجرا روی: GPU مجزا، iGPU اینتل، CPU تنها.
- 12MP→4x روی iGPU < ۹۰ ثانیه.
- هیچ کرشی در تست ۲۰۰ فایلی.
- خروجی بیت‌به‌بیت تکرارپذیر روی یک دستگاه.

**خارج از دامنهٔ M1:** چهره، پس‌زمینه، Diffusion، ویدیو، موبایل.

## ۱۱. اسپرینت پیشنهادی دو هفتهٔ اول (شروع فوری)

1. ساخت مخزن کد: `core/`, `ui/desktop/`, `bench/`, `tests/`.
2. CMake + ncnn (submodule) + یک تست `hello-inference` روی CPU.
3. دانلود `realesrgan-x4plus` + تبدیل/آماده‌سازی ncnn + اجرای یک تصویر ۵۱۲×۵۱۲.
4. CLI حداقلی: `atlas-cli enhance in.jpg out.png --scale 4 --tile 256`.
5. اندازه‌گیری زمان روی ۲ دستگاه و ثبت در `bench/results/`.
6. تصمیم دربارهٔ نام مدل‌های عمومی (بدون کپی برند).
