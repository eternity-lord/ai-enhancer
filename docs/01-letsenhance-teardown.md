## ۲. سطح محصول (چیزی که کاربر می‌بیند)

ناوبری اصلی چهار محصول دارد ✅:

1. **Verbeteren / Boost** — ابزار اصلی: Improve/Upscale (همان چیزی که موضوع این تحلیل است)
2. **Generator** — تولید تصویر از متن (نسخهٔ ۲K در ۲۰۲۶)
3. **Chat-editor** — ویرایش تصویر با دستور زبان طبیعی
4. **Afbeelding naar video** — تبدیل تصویر به ویدئوی کوتاه

به‌علاوه: `Pricing plans`، `My account` (Balance / Profile / Billing)، انتخاب زبان، ورود/خروج.

### ۲.۱ ابزار Boost در UI

- ناحیهٔ `Drop your images / browse` برای آپلود (JPG/PNG/WebP، حداکثر ۵۰MB).
- ستون `IMAGES TO PROCESS` — صف تصاویر.
- پنل راست `OPERATIONS` با سوییچ‌های مستقل:
  - `Upscale & Enhance` (انتخاب مدل + اندازه)
  - `Light AI` (با اسلایدر شدت)
  - `Remove background` (با دسته: General / Car)
  - و در نسخه‌های مختلف: `Sharpen`, `Denoise`, `Enhance faces`, `Color correction`
- تنظیم `Size` با سه حالت: `Auto x4`، `Scale` (۲x/۴x/۸x/۱۶x) یا `Width & Height` + `DPI`.
- دکمهٔ `Enhance` که **هزینهٔ اعتباری لحظه‌ای** را نشان می‌دهد؛ پیش‌نمایش قبل/بعد؛ دانلود (با واترمارک در پلن رایگان).
- `Try all`: اجرای یک تصویر روی چند مدل و مقایسهٔ کنار هم.
- `Presets` برای چاپ/وب/شبکه‌های اجتماعی و پریست‌های دسته‌بندی (مثلاً Car).

## ۶. جریان کاربری (UX Flow)

```
ورود → (کشیدن فایل / browse) → صف IMAGES TO PROCESS
     → OPERATIONS: Upscale&Enhance [مدل] [اندازه] + Light AI [شدت] + Remove BG
     → دکمه Enhance (نمایش هزینهٔ اعتبار)
     → پردازش ابری (چند ثانیه تا چند دقیقه)
     → پیش‌نمایش قبل/بعد + زوم ۱۰۰٪ + Try all
     → دانلود (PNG/JPG) یا ذخیره در حساب
```

نکات تجربهٔ کاربری که ارزش کپی کردن دارند:

- **هزینه قبل از اجرا** روی دکمه نمایش داده می‌شود (شفافیت).
- **Try all** انتخاب مدل را از حدس به مقایسه تبدیل می‌کند.
- **زوم ۱۰۰٪** به‌عنوان توصیهٔ رسمی برای کنترل کیفیت.
- **پریست‌ها** به‌جای تنظیم دستی DPI/ابعاد.
- **تفکیک مدل بر اساس «نوع خرابی»** نه «نوع مشتری» — این یکی از باهوش‌ترین تصمیم‌های محصولی آن‌هاست.

## ۷. API (Claid.ai) — نقشهٔ قابلیت‌ها

عملیات به‌صورت یک **پایپ‌لاین JSON اعلانی** توصیف می‌شوند ✅:

```json
{
  "input": "https://example.com/in.jpg",
  "operations": {
    "restorations": { "upscale": "photo", "decompress": "auto", "polish": true },
    "resizing":    { "width": "200%", "height": "200%" },
    "color_adjustments": { "light": true },
    "background":  { "remove": { "category": "general" } }
  },
  "output": { "format": "png" }
}
```

| گروه | عملیات |
|---|---|
| `restorations` | `upscale` ∈ {`smart_enhance`, `smart_resize`, `digital_art`, `faces`, `photo`} · `decompress` ∈ {`moderate`,`strong`,`auto`} · `polish` (حداکثر ۱۶MP) |
| `resizing` | عرض/ارتفاع عددی یا درصدی، crop/padding |
| `color_adjustments` | روشنایی/کنتراست/اشباع/دمای رنگ/تصحیح نور (Light) |
| `background` | `remove` (general/car)، تولید/جایگزینی پس‌زمینه، سایه، صحنه |
| `padding` / `smart_frame` | افزودن حاشیه، قاب‌بندی هوشمند برای مارکت‌پلیس‌ها |
| `privacy` | blur پلاک خودرو |
| Generative | `ai_edit` با دستور زبان طبیعی، `outpainting`/`zoom_out`، `generative_resize` |
| Generation | `text_to_image`، `ai_fashion_models`، `image_to_video` |
| زیرساخت API | sync + async + batch، webhook، اتصال S3/GCS/Web Folder، rate limit |

OpenAPI عمومی حدود **۲۰ عملیات و ۱۶۴ اسکیما** دارد (بر اساس پروفایل ثالث API Evangelist).

نکتهٔ مهم برای ما: **مدل داده‌ای اعلانی (declarative pipeline) بهترین الگو برای طراحی موتور لوکال است** — همان چیزی که در `05-architecture.md` به‌عنوان «گراف پایپ‌لاین JSON» می‌سازیم.

## ۸. «چطور این کار را می‌کنند» — خلاصهٔ فنی

جزئیات در `02-how-it-works.md`؛ اینجا فقط نقشهٔ کلی:

1. **آپلود** به object storage، ساخت job، ثبت مصرف اعتبار.
2. **صف** (احتمالاً Redis/Kafka) + workerهای stateless روی GKE.
3. **Triton Inference Server** مدل‌ها را سرو می‌کند؛ MIG اجازه می‌دهد یک A100 به چند نمونهٔ کوچک تقسیم شود → چگالی بهتر و اتوسکیل اقتصادی.
4. **پیش‌پردازش**: decode، اصلاح جهت EXIF، تبدیل به sRGB، تشخیص آرتیفکت/نویز/چهره، انتخاب مدل، تقسیم به کاشی در صورت نیاز.
5. **مدل‌ها**: CNN/GAN برای SR، مدل چهره، مدل segmentation برای پس‌زمینه، مدل رنگ، و برای `Ultra` احتمالاً مدل مولد (diffusion) با کنترل شدت.
6. **پس‌پردازش**: blend کاشی‌ها، شارپن نهایی، تنظیم رنگ، resize به ابعاد هدف، encode با پروفایل رنگ، واترمارک در پلن رایگان.
7. **تحویل**: CDN + لینک دانلود + امکان دانلود مجدد بدون واترمارک بعد از خرید.
8. **متریک مصرف** بر اساس مگاپیکسل خروجی × عملیات × مدل.

منبع رسمی: مطالعهٔ موردی Google Cloud/NVIDIA (۲۰۲۲) که A100 + GKE + Triton و اعداد throughput را تأیید می‌کند.

## ۹. فرمت‌ها، رنگ و وفاداری

- ورودی وب: JPG/PNG/WebP؛ پردازش در فضای **8-bit sRGB** (🟡، رایج در این نوع سرویس‌ها).
- خروجی: JPG/PNG (و در API فرمت‌های بیشتر).
- **بدون** پشتیبانی مشخص از ۱۶ بیت، TIFF، CMYK، RAW در وب‌اپ (🟡 بر اساس UI).
- متادیتا: حفظ EXIF/IPTC در وب‌اپ تضمین نشده؛ DPI فقط به‌عنوان پارامتر هدف‌گذاری می‌شود.
- تصاویر `.jpg` به‌صورت خودکار «decompress» می‌شوند؛ یعنی سرویس به پسوند فایل اعتماد می‌کند (نکتهٔ قابل بهبود در ما: تشخیص محتوایی، نه پسوندی).
