# ۰۳ — مشخصات محصول (Feature Spec) و معیار پذیرش

**محصول:** Atlas — Enhancer لوکال، چندسکویی، مستقل از GPU
**نسخهٔ هدف این سند:** ۱.۰
**اولویت‌ها:** `P0` = بدون آن محصول معنی ندارد · `P1` = برابری با LetsEnhance · `P2` = تمایز/فراتر · `P3` = بعد از ۱.۰

## ۱. دامنه

- **در دامنه:** بزرگ‌نمایی/بهبود عکس و گرافیک، بازسازی چهره، حذف نویز/آرتیفکت، اصلاح نور/رنگ، حذف پس‌زمینه، مرمت عکس قدیمی، دستهٔ فایل، خروجی چاپی، CLI، (اختیاری) ویرایش مولد و ویدیو.
- **خارج از دامنهٔ ۱.۰:** تولید تصویر از متن به‌صورت پیش‌فرض (اختیاری/پلاگین)، مدل‌سازی سه‌بعدی، ویرایش ویدیوی بلند، آموزش مدل روی دستگاه.

## ۴. فراتر از برابری (تمایزهای ما)

1. **Auto-Pilot**: تحلیل تصویر → انتخاب مدل/شدت/کاشی + توضیح («چهره‌های کوچک تشخیص داده شد → Strong + Enhance faces»).
2. **پایپ‌لاین قابل‌ویرایش**: گراف گره‌ای (اختیاری) برای کاربر حرفه‌ای، با ذخیرهٔ پریست.
3. **ماسک و ناحیهٔ انتخابی**: SR فقط روی سوژه با حفظ پس‌زمینه.
4. **حالت مقایسهٔ چهارگانه**: ۴ مدل، ۴ کاشی هم‌زمان.
5. **حالت چاپ**: ۱۶ بیت + CMYK soft-proof + DPI واقعی + TIFF/PDF.
6. **حالت سازمانی**: CLI/سرور محلی (localhost API) برای اتوماسیون روی NAS/سرور استودیو.
7. **شفافیت کیفیت**: نمایش «اطمینان بازسازی» (نقشهٔ حرارتی از نواحی توهم‌شده).

## ۶. تعریف «انجام‌شده» (DoD) برای هر قابلیت

1. کد + تست واحد + تصویر طلایی (golden) در مخزن.
2. اجرا روی سه بک‌اند: Vulkan، CPU، و (در دسترس) ONNX EP.
3. سند کاربری کوتاه (یک پاراگراف + تصویر).
4. بنچمارک زمان/حافظه ثبت‌شده در `bench/results/`.
5. بازبینی لایسنس مدل و ثبت در `models/catalog.json`.
6. تست روی حداقل ۲ دستگاه واقعی از دو تیر مختلف.
